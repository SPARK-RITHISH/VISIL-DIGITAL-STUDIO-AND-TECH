# VISIL Digital Studio — Working Model

A standalone, responsive website model for VISIL Digital Studio & Tech.

## Run it

Open index.html in a web browser. No build step or package installation is required.

## File structure

    visil-digital-studio-working-model/
    ├── index.html       Page structure and content
    ├── css/
    │   └── style.css    Styling and responsive layouts
    ├── js/
    │   └── script.js   Navigation, animations, modal, counters, WhatsApp form
    └── assets/          VISIL logo, portfolio, and founder images

The contact form opens WhatsApp with the visitor's completed project brief, ready to send to VISIL.
